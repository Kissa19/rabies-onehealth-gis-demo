ข้อมูลรายอำเภอที่อนุมัติแล้ว

อำเภอผู้สัมผัสABอิมมูโนโกลบูลินCDEC/AE/B

นิยามตัวชี้วัดและข้อจำกัด

A = ผู้เริ่มรับวัคซีน (IM + ID); B = Booster; C = ได้รับวัคซีนอย่างน้อย 3 เข็ม (IM3 + ID3); D = 4–5 เข็ม (IM5 + ID4); E = Booster ครบชุด แสดงอัตรา C/A, D/A และ E/B โดยเป็นสัดส่วนระหว่างตัวแปรที่รายงาน มิใช่หลักฐานยืนยันผลลัพธ์รายบุคคลหรือความครอบคลุมประชากรทั้งหมด

ข้อมูลปีงบประมาณ 2569 เป็นข้อมูลสะสมตาม HDC ณ วันซิงก์ที่ระบุ อาจมีการแก้ไขย้อนหลังและการเปลี่ยนจำนวนหน่วยบริการ ข้อมูลนี้ไม่มีชื่อ เลขประจำตัว หรือข้อมูลรายบุคคล

หมายเหตุคุณภาพ: ชุดข้อมูลที่อนุมัติมี Structural QC ผ่าน แต่ Change QC พบการเปลี่ยนรายชื่อหน่วยบริการจากรอบก่อน จึงควรใช้ประกอบการเฝ้าระวังและอ่านหมายเหตุควบคู่กัน
